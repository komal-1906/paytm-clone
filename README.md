Paytm Clone

A responsive Paytm homepage clone built using HTML and Tailwind CSS.
This project replicates the layout and design of the Paytm website to practice modern frontend development and utility-first CSS with Tailwind.

🚀 Features

Paytm-style homepage layout

Responsive design

Navigation bar similar to Paytm

Recharge and bill payment service cards

Clean and structured UI

Built using Tailwind utility classes

🛠 Technologies Used

HTML5

Tailwind CSS

CSS Flexbox

🎯 Purpose of the Project

This project was created to improve my frontend development skills and gain hands-on experience with Tailwind CSS for building modern UI layouts.
